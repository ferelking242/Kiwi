# Security Policy

  ## Reporting a Vulnerability

  Report security vulnerabilities to: **contact@aivos.io**

  Do NOT open a public GitHub issue for security vulnerabilities.

  ## Supported Versions

  | Version | Supported |
  |---------|-----------|
  | latest  | ✅        |

  ## Secrets

  Never commit API keys, keystore files, or credentials.  
  All signing credentials are stored in GitHub Secrets only.
